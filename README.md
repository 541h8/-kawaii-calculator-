# 🎀 萌萌科学计算器

一个可爱二次元风格的网页科学计算器，单文件 + 音效资源，双击即可使用。

## ✨ 功能一览

### 🧮 基础计算
加减乘除、小数点、正负号、退格、清除、百分比、M+/MR/MC 记忆存储

### 🔬 科学计算
sin / cos / tan 及反三角函数、sinh / cosh / tanh、√ / ³√ / x² / x³ / xʸ、
log / ln / eˣ / 10ˣ / 2ˣ、x! 阶乘、1/x、|x|、mod、nPr、nCr、Rand、
Round / Ceil / Floor，支持 DEG / RAD 切换

### 📈 函数图像解析
输入任意含 `x` 的表达式实时绘制，如 `x^2-4`、`sin(x)^2+cos(x)^2`
- 自动检测渐近线/极点并断线，不画成斜线
- 自动求解零点（与 x 轴交点）与极值点
- 鼠标拖动平移、滚轮缩放、双击复位
- 12 个快捷预设函数

### 💻 进制与位运算
DEC / HEX / OCT / BIN 四进制实时互转，8/16/32/64 位字长，AND / OR / XOR / NOT / 移位
（基于 BigInt，64 位整数不丢精度）

### 📊 统计 · 🧩 方程 · 📐 几何 · 💰 金融 · 📐 单位换算 · 📅 日期计算
- 统计：均值、中位数、Q1/Q3、极差、方差、标准差、变异系数、偏度、峰度
- 方程：一元二次/三次、二元/三元一次方程组
- 几何：圆、三角形（海伦公式）、矩形、正多边形，输入一项自动反推其余
- 金融：等额本息、复利终值、现值贴现、税费/小费
- 换算：长度、重量、温度、面积、速度，实时双向
- 日期：相差天数、日期加减

### 🎀 音效系统
- 6 种按键音效预设（软萌短促 / 水晶铃音 / 气泡 / 温暖 / 复古 / 静音）
- 7 句萝莉语音（算对啦 / 出错啦 / 嗨 / 喜欢你 / 嗯？ / 好厉害 / 晚安）
- 主音量 / 按键音量 / 语音音量三级独立调节

### 🎭 其他
12 种情绪表情角色（点击摸摸会害羞）、计算彩蛋（=42 终极答案）、
🌙 暗色主题、🖼️ 换壁纸、📋 计算历史（本地保存）、
点击结果复制、全键盘快捷键（G 绘图 / B 换图 / U 换算 / D 日期 / H 历史 / V 主题 / ESC 关闭面板）

## 🚀 使用方法

1. 下载本仓库全部文件（`calculator.html` 与 `sounds/` 文件夹保持同级）
2. 双击 `calculator.html` 用浏览器打开即可使用
3. 推荐用 Chrome / Edge / Firefox 等现代浏览器

> ⚠️ 音效通过 fetch 加载，部分浏览器（尤其微信/QQ 内置浏览器）会拦截本地文件请求，
> 导致听不到声音。此时请换系统自带浏览器，或把文件放到本地服务器/静态托管上访问。

## 📦 技术说明

- 纯前端单页应用，无任何外部依赖，离线可用
- 表达式引擎支持隐式乘法（`2x`、`x sin(x)`）、幂运算（`x^2`、`(x+1)^3`）、
  嵌套括号、sinh/cosh/tanh、abs、log、exp、复数域处理
- 安全编译：先 tokenize → 处理幂运算 → 补隐式乘法 → 重组，
  不执行任意代码，输入恶意字符串也不会执行
